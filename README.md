
# Customer Support Portal

A customer support ticket system built with a Laravel API and a Vue 3 frontend.

This is a learning project in my full-stack journey.

## Project Status

Work in progress. Core features are implemented, while additional functionality and improvements are still being developed.

## Features

- Create, view and edit support tickets.
- Manage ticket categories.
- Log in and out using Laravel Sanctum.
- Restrict access based on user roles and ticket ownership.

## Technologies

- **Frontend:** Vue 3, TypeScript, HTML and CSS
- **Backend:** Laravel and PHP
- **HTTP client:** Axios
- **Authentication:** Laravel Sanctum
